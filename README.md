## Реализация многопоточности в библиотеке для Монте-Карло вычислений ядро-ядерных столкновений

В облати исследований релятивистских ядро-ядерных столкновений существует множество моделей, описывающих разные этапы столкновения. Для их организации в нашем коллективе была создана библиотека [COLA](), использующая принципы конвейера данных и внедрения зависимостей.

Следующим этапом развития библиотеки является интегрирование многопоточности в её структуру. Это позволит упростить запуск вычислений в несколько потоков (прямое использование функционала библиотеки вместо внешних bash скриптов) и оптимизирует процесс вычислений: в связи со стохастическим характером Монте-Карло моделирования, время на вычисление одного события может сильно флуктуировать, из-за чего запуск нескольких задач с последовательным вычислением большого количества событий часто приводит к простаиванию части ресурсов и, как следствие, увеличение времени моделирования.

В задаче предлагается разработать код для многопоточной работы библиотеки. Необходимо создать архитектуру, поддерживающую подход внедрения зависимостей и требущую минимальных изменений в существующих интерфейсах библиотеки. для создания
